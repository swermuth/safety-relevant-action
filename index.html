Safety-Relevant Passenger Action Detection in Public Transportation: A Comparative Evaluation of Frame-Based Approaches

Stella Katharina Wermuth1,2, Qazi Arbab Ahmed1, Thorsten Jungeblut1
1 Bielefeld University of Applied Sciences and Arts, Bielefeld, Germany
2 Bielefeld University, Bielefeld, Germany
Paper Code PMOF Dataset arXiv

Abstract

Passenger monitoring is essential for autonomous public transportation, where onboard personnel is absent. Safety-relevant events must therefore be detected automatically and reported to a central control unit. In this study, we develop and evaluate two frame-based approaches for detecting safety-relevant passenger actions using the PMOF dataset, which provides oriented bounding-box-level (obb) annotations for four actions: seated, standing and lying. The first approach uses a custom-trained YOLO26-obb model to detect these actions at the passenger-instance level and trigger an alert when a safety-relevant action is detected. However, the three actions are highly imbalanced, accounting for 96\%, 3\% and 1.0\% of annotated instances, respectively. To mitigate this imbalance, the second approach formulates the task as frame-level classification (cls) using a custom-trained YOLO26-cls model, distinguishing between normal and safety-relevant frames. While this increases the number of samples representing safety-relevant events, it combines distinct actions into a single class and may therefore introduce greater classification ambiguity. We evaluate both approaches on a real-world PMOF test set, comparing their ability to generate correct safety-relevant alerts and investigating data-balancing strategies. Our results assess the trade-off between instance- and frame-level approaches and provide insights for developing reliable passenger monitoring systems for public transportation.
